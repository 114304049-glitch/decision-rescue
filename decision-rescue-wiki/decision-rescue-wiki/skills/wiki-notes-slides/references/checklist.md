# 驗收清單

- 每個重要主張、表格比較與公式可追溯至 Wiki，保留原有內容性質。
- raw 尚未整理、新搜尋文獻未混入正文、結論、圖表或講者備註。
- 建議文獻核對標題、作者、年份、閱讀範圍與連結；下載型態標示正確。
- notes 記錄實際 Wiki 版本；outline 對應 notes；HTML 對應 outline。
- 新版本不覆寫舊交付；索引及操作紀錄已更新。
- 封面保留 A 款餐點照片，內頁蔬菜點綴稀疏，表格與公式頁不強塞圖案。
- HTML 實測來源連結、換頁、窄螢幕、字體、長標題、內容溢出與公式。
- 列印、離線、全螢幕等功能只有實測通過才能宣稱支援。
- 專案內容有異動時執行 npm run check；影響網頁時執行 npm run build。現有 check 不涵蓋 notes／slides／presentations，須另做上述人工與瀏覽器檢查。
- 以「已完成／未驗證／待辦」回報，不把技能規則存在當成成果已完成。
