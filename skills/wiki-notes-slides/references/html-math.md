# HTML 與 LaTeX 實作規格

## 格式
notes 與逐頁稿使用 `$...$` 行內公式、`$$...$$` 獨立公式。公式、符號、單位、數值與意義都需對應 Wiki；無公式需求就不強塞公式。
普通金額使用「150 元」避免美元符號被誤判。程式碼區塊內的 LaTeX 保留原文，不當作公式渲染。

## 渲染
製作 HTML 時選擇 KaTeX 或 MathJax，先檢查專案已有依賴，再驗證所選版本文件；不得假稱現有 markdown-it 已支援數學公式。
固定版本，記錄套件與授權。一般模式可用 CDN 但需說明需連網；要求離線時打包渲染器、字型與必要資源，驗證斷網可用。
處理不支援指令、未配對符號、長公式、中文與公式混排；有錯誤即修正或明確指出，不能靜默顯示錯誤碼。
不任意開啟原始 HTML、trust 模式或可執行指令。印刷及瀏覽器版公式皆須檢視，不只檢查原始碼。

## 簡報可用性
基本上一頁一節，提供清楚的上一頁／下一頁與頁碼；鍵盤左右鍵可切換，不攔截文字輸入框的正常操作。其他功能（全螢幕、目錄、講者模式）依使用者要求加入。
保留真實文字與 table；來源用 anchor，確保返回 Wiki 的路徑正確。手機可縮放或改成可讀的直向版面，不裁切內容。
如提供列印 PDF，設定逐頁換頁並隱藏操作按鈕，檢查公式、文字與來源不被裁切。尚未實作時不得標示已支援。
對 prefers-reduced-motion 減少動畫；預設僅淡入，不使用干擾閱讀的轉場。

## 下載與 Wiki 化
文獻頁分清楚「已使用 Wiki 來源」與「待收錄文獻」。公開下載連結優先穩定的原站檔案網址；不能直接下載時提供原文頁，不造假連結。
靜態 HTML 的下載按鈕不會自動寫入 raw/ 或修改 GitHub。只有在後端與認證確實完成時才能提供真正的一鍵匯入；未實作前以「下載原文」與操作說明呈現。
